# Karjeras spēks

Star Wars iedvesmota karjeras motivācijas lapa latviešu valodā ar Orbitron fontu.

Palaišana: `npm start`, pēc tam atver http://localhost:3000.

Pieci jQuery teksta efekti: virsraksta parādīšanās, ievada ieslīdēšana, tekstu parādīšanās ritinot, misijas teksta slēpšana un parādīšana ar `hide()` / `show()` un automātiska citātu maiņa. Apraksts sākumā ir paslēpts. Uzbraucot misijas virsrakstam ar peli, apraksts parādās; noņemot peli, tas pazūd. Pogas nav izmantotas. Samazinātas kustības režīmā animācijas ir izslēgtas.

jQuery tiek glabāts lokāli mapē `vendor`. Google Fonts ielādei vajadzīgs internets; bez tā darbojas rezerves fonti. Neoficiāls mācību projekts, kas nav saistīts ar Lucasfilm.
